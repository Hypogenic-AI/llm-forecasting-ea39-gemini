# Cloned Repositories

## Repo 1: Time-LLM
- URL: https://github.com/KimMeen/Time-LLM
- Purpose: Reprogramming LLMs for Time Series Forecasting (Short-term High-data).

## Repo 2: ForecastBench
- URL: https://github.com/forecastingresearch/forecastbench
- Purpose: Evaluation framework for LLM forecasting on real-world events (Long-term Low-data).

## Repo 3: Logo-LLM
- URL: https://github.com/ouwen18/Logo-LLM
- Purpose: Local and Global Modeling with LLMs for Time Series Forecasting.

## Repo 4: One-Fits-All (OFM)
- URL: https://github.com/DAMO-DI-ML/NeurIPS2023-One-Fits-All
